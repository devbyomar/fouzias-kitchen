## Recommended export specs
- **Format:** JPG (compressed, 75–85% quality) for photos; SVG/PNG for logo.
- **Width:** 1600px max for hero/story; 1200px for product cards; 1000px for gallery.
- **Color profile:** sRGB.
- **File size:** target < 250 KB per image where possible.

A free batch tool like **Squoosh** (squoosh.app) or **TinyPNG** is perfect for compressing without losing the warm tones.
